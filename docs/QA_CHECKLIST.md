### คนสวน (ควรเหลือ 3 ขั้น)

- [ ] สแกน → เลือก "ตัดขาย" → บอทขอ **"น้ำหนัก จำนวนลูก"** ในคำถามเดียว **ไม่ถามเกรด ไม่ถามราคาแล้ว**
- [ ] พิมพ์ `45 18` → ไปขั้นถ่ายรูปเลย
- [ ] พิมพ์ผิด (`45` อย่างเดียว / ตัวหนังสือ / `0`) → บอทเตือน ไม่ข้ามขั้น
- [ ] **สแกนต้นเดิมซ้ำ (ตะกร้าที่ 2)** → บอทบอกว่า *"ต้นนี้วันนี้บันทึกไปแล้ว N ตะกร้า รวม X กก."*
- [ ] เลือก "เสียหาย" → ถามจำนวนลูกอย่างเดียว ไม่ต้องชั่ง
- [ ] เจ้าของอนุมัติ → เช็คชีต `การเก็บเกี่ยว` ว่า **เกรด/ราคาว่าง** และ **คอลัมน์ `รอบที่` มีค่า** `H-2568xxxx`
- [ ] ยอด "คงเหลือบนต้น" ยังหักถูกเหมือนเดิม

### เจ้าของ — บันทึกการขายรายวัน

**ทางเข้ามี 2 ทาง** (Rich Menu ไม่มีปุ่มนี้ เพราะต้องทำรูปใหม่ทั้งใบ):

- [ ] กดเมนู **"ภาพรวม"** ใน Rich Menu → เลื่อนลงล่าง เห็นปุ่ม **📦 บันทึกการขายวันนี้** (สีส้ม) และ **บันทึกการขายของเมื่อวาน**
- [ ] หรือ **พิมพ์ `บันทึกการขาย`** ในแชท (พิมพ์ `ขาย` / `บันทึกขาย` ก็ได้)
- [ ] กดแล้ว → เห็นสรุป *"ตัดได้ N ต้น · M ลูก · น้ำหนักรวม X กก."*
- [ ] พิมพ์หลายบรรทัด `A 60 130` / `B 40 90` → เห็นการ์ดสรุปพร้อมยอดเงินรวม
- [ ] กดยืนยัน → ใส่ชื่อผู้ซื้อ (หรือ `-` เพื่อข้าม) → บันทึกสำเร็จ
- [ ] เช็คชีต `รอบขาย` ว่ามี 1 แถวต่อ 1 เกรด และ `รวมเงิน` คำนวณถูก
- [ ] **บันทึกซ้ำวันเดิม** → ต้องทับของเก่า **ไม่ซ้อนกัน**
- [ ] คนสวน/ลูกค้ากดปุ่มนี้ → ถูกปฏิเสธสิทธิ์
- [ ] วันที่ยังไม่มีรายการตัด → บอทเตือน ไม่ให้กรอกเปล่าๆ

### รายงาน

- [ ] เมนู "สรุปตามเกรด" → ตัวเลขเป็น **กิโลกรัม** (ไม่ใช่จำนวนลูก) และตรงกับที่กรอกในรอบขาย
- [ ] เมนู "ภาพรวม" → รายได้ตรงกับผลรวมในชีต `รอบขาย`
- [ ] **หน้าเว็บแท็บ "รายได้"** → ตัวเลข**ไม่เป็น 0** และตรงกับชีต `รอบขาย` (รายการแสดงเป็น "รวมทั้งรอบ (วันที่)" ไม่ใช่รายต้น เพราะเกรด/ราคาเป็นของทั้งรอบ)
- [ ] **หน้าเว็บ → ป๊อปอัปรายละเอียดต้นไม้ → ประวัติ** → รายการตัดขายต้องขึ้นไอคอนถุงช้อปปิ้งสีเขียว **ไม่ใช่** ไอคอนเตือนสีเหลือง (เดิมใช้เกรดเป็นตัวแยก ตอนนี้ใช้เหตุผล)
- [ ] ถ้ามีวันที่ตัดแล้วยังไม่บันทึกขาย → **ได้ push เตือน** (รอ trigger รอบถัดไป หรือรัน `checkAndPushPending()` เองใน editor)

### Migration / ข้อมูลเก่า

- [ ] ตัวเลขรายได้ย้อนหลังจากข้อมูลเดิม (ที่มีราคาในแถว) **ยังไม่หายไป** — ระบบ fallback อ่านให้
- [ ] ประวัติในหน้าต้นไม้: รายการใหม่ไม่โชว์เกรดรายต้น รายการเก่ายังโชว์ได้

## 6. Flow ตัดจำหน่าย (เวอร์ชันเก่า — ข้ามได้ถ้า deploy ชุดใหม่แล้ว)

> เดิม: กด "ส่งรูปครบแล้ว" แล้วบอทเงียบ ทำรายการไม่จบเลย

- [ ] กด "ส่งรูปครบแล้ว" → **ต้องขึ้นการ์ดสรุปรายการ** (จุดที่เคยเงียบ)

- [ ] ยังไม่ส่งรูปแล้วกด "ส่งรูปครบแล้ว" → ขึ้นเตือน "ยังไม่ได้ส่งรูปเลยครับ"
- [ ] ระหว่างรอรูป พิมพ์อะไรก็ได้ → บอทบอกให้ส่งรูป ไม่เงียบ

- [ ] เจ้าของกดอนุมัติ → เช็คชีต "ผลผลิต" ว่า ตัดแล้ว/คงเหลือ ขยับถูก
